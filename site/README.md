# Fairplate site

The published site (https://goofturtles.github.io/fairplate/). Static files with no build step: serve this folder with
`python -m http.server 3540 -d site`. See the repo's main README for how it works.

`?sample=1` opens the original design screens with sample restaurants and prices (fictional, for design checks only).
The normal site shows real places and only the prices captured by the extension.
